# Artwork

The game uses compressed **.webp** images (about 10% of the size of the PNGs, so it loads
quickly on school wifi). The full-size PNG originals live in `art-originals/` on your own
computer (not published). For new art: save the PNG into `art-originals/`, then convert it
to a .webp with the same name in `assets/` (quality 82, keep transparency).

Until a file exists, the game shows a labelled placeholder with the expected path.

Style: historically grounded Ancient Rome, painted illustration, warm natural colours. Not cartoonish, not fantasy.
